### ⑨-2 확률 보정(Platt scaling, `qa_calib.py`)
선택 세트(FF++ val + DFD-val, 두 세트 같은 무게)에서 logit(영상 점수)에 1차 로지스틱을 맞추고, 보고 세트에 기준값 0.5로 적용했다. 모델 자체는 그대로이고 점수를 확률로 바꾸는 함수만 바뀐다.

| 세트 | P0 ECE 원래→보정 | 최종 ECE 원래→보정 | P0 ACC 보정 후 | 최종 ACC 보정 후 | 최종 bACC 원래→보정 |
|---|---|---|---|---|---|
| FF++ test | 1.8 → 6.8 | 11.6 → 7.0 | 87.3 | **88.0** | 86.3 → 70.9 |
| Celeb-DF | 36.7 → 10.9 | 38.9 → **5.2** | 72.0 | **74.1** | 61.3 → 69.7 |
| FaceShifter | 20.2 → 16.1 | 19.1 → 16.1 | 57.5 | **63.6** | 63.3 → 63.6 |
| DFD-test | 16.7 → 6.5 | 33.1 → **6.2** | 82.1 | **82.7** | 68.8 → 59.1 |

- 같은 보정을 두 모델에 적용하면 **ACC는 최종 모델이 네 세트 모두 같거나 높다**(+0.7, +2.1, +6.1, +0.6).
- ⑨-3 신뢰구간(`qa_calib_ci.py`, 영상 짝 bootstrap 2,000회, 보정 함수는 선택 세트로 고정): ΔACC FF++ +0.67 [−0.38, +1.76], Celeb-DF +2.12 [−0.77, +5.08], **FaceShifter +6.07 [+2.86, +9.52] ✔**, DFD +0.60 [−0.34, +1.55]. ΔbACC FF++ +2.11 [−0.24, +4.58], Celeb-DF +0.01 [−3.16, +3.32], **FaceShifter +6.07 [+2.81, +9.34] ✔**, **DFD +2.25 [+0.16, +4.46] ✔**. → 같은 보정 조건에서는 정확도가 어디서도 떨어지지 않고 FaceShifter에서 확실히 오른다.
- 기준값 0.5에서 ACC가 떨어진 원인은 모델의 판별력이 아니라 확률 보정과 기준값이라는 해석을 뒷받침한다.
- 단, 선택 세트는 가짜가 많아(DFD-val 가짜 79%) 보정이 ‘가짜’ 쪽으로 기울고, 그 대가로 FF++·DFD의 bACC가 떨어진다. ACC를 볼지 bACC를 볼지(= 오탐과 미탐 중 무엇이 비싼지)는 운영 목적에 따라 정해야 한다.

- ③ 상단으로 가는 gradient 크기(SBI 학습 배치 640개, 학습 때와 같은 손실): 같은 출발점 θ0에서 U0(분기 없음) 7.13 vs U3(분기 있음) 0.99~2.74 → **분기가 상단으로 가는 학습 신호를 2.6~7배 줄인다**. best 체크포인트에서도 U0 2.9 vs U3 1.2~1.4.
  - 그런데 가중치 변화량은 비슷했다(7.56% vs 7.80%). AdamW는 gradient 크기를 정규화해 거의 같은 크기로 갱신하므로, 분기는 상단이 움직이는 '양'이 아니라 '방향'을 바꾼 것으로 해석된다(분기가 SBI 특화 신호를 맡고 남은 신호로 상단이 움직임 → 판단 순서 보존). 앞의 U0s/U3s 분석과 일관된다.
- 배치: 모두 qa_answers.md(메커니즘 세부라 본문 미반영).

## ① Celeb-DF 재압축 — `ref/qa_followup/qa_cdf_encode.py`, `code/qa_cdf_eval.py`, `ref/qa_followup/qa_cdf_stats.py`, `qa_cdf.json`
- 방법: Celeb-DF 평가 프레임(256 PNG)을 영상별로 이어 libx264 crf 23·40(FF++ c23·c40과 같은 코덱·품질 값)으로 압축 → 복원 → 224 축소(기존 규칙). PSNR 원본 대비 c23 37.9 dB, c40 29.3 dB. 논문 모델 출력 캐시를 새로 만들어 평가. 도구: 기본 miniconda에 imageio-ffmpeg 0.6.0(ffmpeg 7.1) 설치(사용자 승인).
- 검증: 원본 읽기 재현(기존 cdf_img와 동일), 원본 프레임 logit 차이 0, 원본 조건 최종 모델 점수 = 은행(차이 0).
- 한계: 평가 프레임(영상당 ≤32장)만 이어 붙여 압축 → 실제 영상보다 프레임 간 예측이 약하다.
