## 시도할 방법
| # | 근거 | 방법 | 학습 |
|---|---|---|---|
| N1 | 병합에서 baseline 상단과 분기가 받는 비율이 같음(b) | **모듈별 병합 비율**(상단 b_top, 분기 a_br·b_br) + 상단만/분기만 병합 분해 | 없음 |
| N2 | task vector 사이 간섭 | **TIES-merging**(상위 k% 크기만 남기고 부호 선출) · **DARE**(무작위 버림 + 재척도) | 없음 |
| N3 | 같은 θ0를 공유하는 모델이 더 있음 | **다중 전문가 병합**: U3f, P3_sbi(S8), U3m(혼합), Ds(증류), P4c(anchor)를 탐욕적으로 추가 | 없음 |
| N4 | 영상 점수 = trimmed mean 고정 | **영상 집계 방식**(평균·중앙값·logit 평균·상위 50% 평균) 선택 세트로 선택 | 없음 |
| T1 | SBI 전문가가 불안정(seed 표준편차 1.44), 별도 학습 모델 병합 | **P3에서 출발한 SBI 추가 학습** → P3와 같은 경로 위 보간(WiSE-FT) | seed 0 선별 → 3 |
| T2 | 〃 | **EMA 가중치**(decay 0.999)로 SBI 전문가 학습 | 〃 |
| T3 | 〃 | **낮은 학습률(1e-5)** SBI 전문가 | 〃 |
| Z | — | 최종 조합(비용별), 보고 세트 판정, 문서 반영 | — |
