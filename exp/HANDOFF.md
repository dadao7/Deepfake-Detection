## 0. 한 문단 요약

DeepSight(딥페이크 탐지 졸업 프로젝트). 저자 공개 가중치 M2F2-Det(CLIP ViT-L/14-336 + EfficientNet-B4)를 **고정**하고, 그 위에 우리가 쌓은 기능
(세부 crop 분기 → heatmap/Top-K → 국소 패치 정규화/동적 결합 → detach 제거/seg head)을 단계별로 얹는다.
**같은 데이터·학습법·epoch·seed로 단계마다 성능을 재서** 각 기능의 실제 기여도를 밝히고, 효과가 없으면 이유를 적는다. 최종 목적은 **논문 작성**이다.
앱(Expo)·서버는 이번 작업과 무관하다.

## 4. 이전 세션에서 밝혀낸 사실 (논문 소재이자 설계 근거)

- **P0 (논문 모델 평가, 완료):** 저자 가중치, FF++ c40 공식 test 700영상 × 100프레임, fp32. 결과는 `ref/p0/p0_metrics.json`.
  영상 AUC **95.22**(저자 코드 그대로면 95.11, 논문 보고 96.58 → **공개 가중치로 논문 수치 재현 안 됨, 비교 기준은 우리가 잰 P0**), ACC@0.5 91.00, 균형 정확도 84.20, **오탐률(진짜→가짜) 27.1%**, 미탐률 4.5%. 방식별 AUC: Deepfakes 98.24 / FaceSwap 96.45 / Face2Face 96.21 / NeuralTextures 89.96. 프레임 단위 AUC 91.21.
  우리 학습 코드의 `load_model`이 읽는 baseline 가중치와 저자 가중치는 동일(1,914개 파라미터 모두 같음).
- **fp16 평가:** fp32 대비 프레임 확률 평균 차이 0.0008(최대 0.021), 영상 AUC 94.765 vs 94.735(차이 0.03%p, 210영상 부분집합) → **평가는 fp16 혼합정밀도로 해도 됨**(모든 설정 동일 정밀도).
- **평가 함정(논문에 쓸 수 있음):** ① 1학기 학습/검증 분할에서 **공식 test 140개 중 115개가 학습 쪽에 포함(데이터 누수)**, 신원 겹침도 있음(수치 66/200은 요약 기록 기준, 재확인 필요) ② 최적 기준값 ACC(테스트에서 기준값 선택)가 **진짜의 27% 오탐을 가림** ③ 저자 코드의 라벨 귀속 버그 ④ 클래스 4:1 불균형 ⑤ **detach가 있어도 heatmap head의 BatchNorm 통계는 학습 중 바뀜**(가중치는 그대로, running_var 최대 차이 22,728) — 이전의 "사전학습 상태 그대로"는 가중치에만 맞는 말.
- **seg head 구조적 사실:** baseline이 고정이면 seg head는 분류 성능(AUC·ACC)을 바꾸지 못한다. 효과는 **위치 정확도**로만 잰다.
- **속도 측정:** 학습 1스텝(배치 16) 235ms 중 고정 baseline 계산이 178ms(76%). baseline 출력(b_3 fp16 64.3KB/프레임 + logit)을 캐시하면 1스텝 37ms. 랜덤 입력의 fp16 NaN은 측정 인공물이고 실제 프레임 gradient는 유한(norm 0.01~0.8). 측정 스크립트는 `ref/bench/`.

### 5.2 설정 정의 (모두 crop 64로 통일)
| 설정 | 구성 | 학습 | 비고 |
|---|---|---|---|
| **P0** | 논문 모델 | 없음(평가만) | **완료** |
| **P1** | + 세부 crop 분기: 특징 평균 기반 crop 1개, 고정 α=0.5, 패치 정규화 없음 | 100% ×3seed + 25/50% | **SBI 초기화 없음**. 1학기 코드는 남아 있지 않아 옵션으로 재구현 |
| **P1′** | P1 + SBI 사전학습 초기화(detail branch) | 100% ×3 | SBI 효과를 P1→P2 차이에서 분리 |
| **P2a** | + heatmap만(heatmap 위치 crop 1개, k=1) | 100% ×3 | SBI 초기화 |
| **P2b** | + top-3만(특징 평균 맵의 상위 3개 peak crop, heatmap 없음) | 100% ×3 | SBI 초기화(detail). *정의는 설계 해석이므로 PROTOCOL.md에 명시* |
| **P2** | + heatmap + Top-3 | 100% ×3 + 25/50% | |
| **P3a** | P2 + 국소 패치 정규화(Method 4)만, 고정 α | 100% ×3 | |
| **P3b** | P2 + 동적 결합 MLP만, 패치 정규화 없음 | 100% ×3 | |
| **P3** | P2 + 둘 다 (= **현재 모델**, detach 있음) | 100% ×3 + 25/50% | |
| **P4a** | P3 + **detach 제거만**(희소성 손실·학습형 α 등 다른 변경 금지) | 100% ×3 + 25/50% | |
| **P4b** | P3 + 고정 seg head | 추가 학습 없음 | 분류 결과 = P3. 위치 평가만 다름 |
| **P4** | P4a + 고정 seg head | 추가 학습 없음 | 분류 결과 = P4a |

- 학습 횟수: 100% 9설정 × 3seed = 27회, 데이터 양별(25·50%) 4설정(P1·P2·P3·P4a) × 2 × 3seed = 24회. 합계 51회.
- **SBI 사전학습은 새 코드로 다시 한다**(공식 train 원본 523개로 SBI 이미지 생성, 공식 val 원본 88개로 체크포인트 선택). heatmap head(11×11 GT에 focal loss)와 detail branch(GT peak 위치 crop: 가짜 vs 같은 위치 진짜)를 함께 사전학습해 1학기 `pretrained_heatmap_detail.pth`를 대체한다. 1학기 파일은 건드리지 않는다.
- **seg head = SBI 사전학습 직후의 heatmap head를 복사해 고정한 것**(BN 통계 포함 고정). baseline이 고정이라 b_3가 모든 설정에서 같으므로, SBI 마스크로 따로 학습한 seg head와 수학적으로 같다.
- **heatmap head의 BN 처리**(학습 모드로 통계가 변하는 원본 동작을 재현할지 고정할지)는 S2에서 원본 동작을 먼저 정확히 확인한 뒤 PROTOCOL.md에 명시한다.

## 7. 논문 가치 평가 (이전 세션 결론 — S7에서 실제 결과로 갱신)

- detach 제거 단독은 방법론 기여보다 **버그 수정에 가깝다** → ablation 한 줄. seg head는 분류 성능이 구조적으로 불변이라 **위치 정확도(설명 충실도)**로 가치를 보여야 한다.
- 성능이 오르지 않아도 "detach 제거 시 heatmap 위치가 위조 영역에서 멀어지는 정도의 정량화 + 분리한 seg head가 위치 설명을 지킴"은 **분석 논문**으로 성립.
- 오른다고 인정받으려면: seed 3개 모두 같은 방향, 향상폭이 seed 표준편차의 2배 이상, 보통 AUC 1~2%p 이상. FF++ 안은 포화라 **Celeb-DF 같은 처음 보는 데이터에서의 향상**이 더 설득력.
- 대상: **국내 학술대회(KCC·KSC·ACK 학부생 논문)는 충분**, 국제 학회는 이번 학기엔 어려움.
- 핵심 표는 **단계별 ablation(P0→P4)**. 일부 기능이 효과 없다고 나와도 그 자체가 신뢰를 높인다. 평가 함정(§4)도 독립된 기여로 쓸 수 있다.
- 먼저 확인할 것: 현재 Celeb-DF AUC(약 75%)가 논문이 보고한 교차 데이터셋 수치와 얼마나 다른지.

### 7.1 S7 실제 결과로 갱신 (2026-10-15, 근거: `reports/S7_report.md`)
- **위의 예상과 달라진 점**
  - **detach 제거는 "버그 수정"이 아니라 해롭다.** Celeb-DF AUC가 −6.4(best)·−7.2(last)로, seed 3개 모두 떨어졌다. heatmap은 얼굴 중앙으로 무너진다(조작 경계 적중 35% → 5%). detach는 heatmap을 보호하는 장치였다.
  - **seg head를 분리하면 위치 설명이 지켜진다.** 고정 seg head의 경계 적중은 35%, 얼굴 중앙 기준선은 0%다. "분석 논문으로 성립"한다는 예상이 실제 수치로 뒷받침됐다.
- **향상 여부**: 덧붙인 기능 중 기준(seed 3개 같은 방향 + 2SD)을 넘겨 AUC를 올린 것은 없다. 현재 모델 P3 vs 논문 모델 P0는 차이가 불분명하다(FF++ 95.11 vs 95.22, Celeb-DF 76.86 vs 76.15).
  - 기능의 실제 역할은 두 가지다. heatmap 위치 crop은 균형 정확도 +2.6, 동적 결합 + 패치 정규화는 후반 과적합 붕괴를 막는다(last Celeb-DF +7.1).
  - 원인: 고정 baseline이 학습 데이터를 이미 맞춘다(1 epoch부터 학습 정확도 97~98%). detail 분기 단독 Celeb-DF AUC는 54~63이고, 동적 α는 진짜/가짜를 가리지 않는 전역 가중치다.
- **논문 수치 확인(완료)**: 논문 Table 3의 Celeb-DF 95.10은 SBI 학습 변형("w/SBI")의 수치다. c40 학습 모델은 Table 4에서 74.82로, 우리 P0 76.15와 맞는다. FF++ c40은 논문 96.58 vs 공개 가중치 95.22.
- **평가 함정 확정치**
  - 1학기 분할 누수: test 140영상 중 115개, test 신원 140개 중 126개가 학습 쪽에 있었다.
  - 테스트에서 고른 기준값 정확도가 오탐률 27%를 가린다.
  - 라벨 귀속 버그: AUC −0.11
  - 위치 지표의 중앙 편향: 중앙 기준선 최댓값 적중 99%. 그래서 경계 지표가 필요하다.
- **논문 구도 제안**: "고정된 강한 탐지기 위 국소 분기의 기여 재평가 — 통제 ablation, 위치 설명, 평가 함정". 국내 학술대회 분석 논문으로 충분하다. 국제 학회는 성능 향상이 없고 데이터셋이 하나라 어렵다.
